# Issue tracking

Public issue tracking, bug reports, and feature proposals use
[GitHub Issues](https://github.com/Sallos725/SAGA/issues).

Repository ADRs (`docs/adr/`), product direction ([DIRECTION.md](DIRECTION.md)), roadmap
([IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md)), and progress reports (`docs/progress/`) are
the canonical sources for design decisions, supported contracts, and verification status.

## Historical references

Earlier ADRs, roadmap notes, and progress reports occasionally reference pre-public tracker IDs
such as `SAGA-1` through `SAGA-46` (from an internal Plane project) and `AGE-*` (from an earlier
Linear workspace). Those IDs are kept as historical provenance only; all active public discussion
and tracking happen in GitHub Issues and Pull Requests.
